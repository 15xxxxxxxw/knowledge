# Knowledge backend

以本地学习源码为基础的 Java 知识库后端。来源：
https://gitcode.com/susan_java/knowledge-base-backend

本上传副本不包含原 Git 历史、数据库数据导出、私有文档、IDE 配置和原环境凭证。
保留源码中的作者署名；本项目不另行授予原始代码许可证。

## 构建

使用 JDK 21、Maven 3.9：`mvn -B test`。
单元测试不需要启动应用，也不会连接原配置中的服务器。

## 运行配置

原有远程基础设施地址在此副本中改为回环地址；真实连接信息通过本地配置或环境提供。
参见 ENVIRONMENT.md。Spring 不会自动读取普通 .env 文件，请在终端、IDE 或部署环境中设置变量。
所有服务必须使用相同的随机 JWT_SECRET；不要使用源码中的演示占位值。
仅准备了源码与修复迁移，未发布含用户数据的数据库初始化导出；运行前需单独准备结构、角色和基础字典。
本次不包含前端，前端仍在本地源代码目录中。
